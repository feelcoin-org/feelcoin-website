What is Feelcoin?

Open foundations. Independent identity.

Feelcoin deliberately builds on mature open-source cryptocurrency technology while operating as its own blockchain with its own genesis, network, addresses, chain history, treasury rule, releases and infrastructure.

Built to be inspected

Feelcoin does not present inherited technology as a clean-room invention. Its core derives from Monero technology and retains transparent upstream attribution.

The project focuses its own development on an independent network, transparent economics, accessible CPU mining, public infrastructure, wallets and an ecosystem whose behavior can be checked in source code and on-chain.

Start Mining

Point RandomX at Feelcoin.

The official pool supports standard and TLS mining. Your Feelcoin wallet address is your miner identity.

Standard connection 
xmrig -o pool.feelcoin.org:4242 -u YOUR_FEELCOIN_WALLET_ADDRESS -p x
TLS connection ENCRYPTED 
xmrig -o pool.feelcoin.org:4244 -u YOUR_FEELCOIN_WALLET_ADDRESS -p x --tls

Official pool fee: 0.5% · Reward accounting: PPLNS. Mining profitability is variable and is not guaranteed. Check the pool for current network and payout information.

Open-Source Lineage

Transparent about where it comes from.

Feelcoin's core software is derived from Monero technology. The project does not claim inherited cryptographic, wallet, networking or RandomX components were independently invented. Feelcoin operates as an independent blockchain with its own genesis, network configuration, chain state, treasury rule, infrastructure and development path.

Security

Verification matters.

Feelcoin is an early-stage independent network. Mainnet functionality does not constitute an independent security audit. Protect wallet seeds and private keys, verify official domains and release checksums, and inspect the open-source implementation when meaningful value is involved.
