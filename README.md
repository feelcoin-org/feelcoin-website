# 🌐 Feelcoin Official Website

**The official website for Feelcoin (FEEL), an open-source RandomX Proof-of-Work cryptocurrency.**

🌐 **Visit:** https://feelcoin.org  
🪙 **Motto:** *In Feels We Trust.*

This repository contains the Feelcoin project's public website: the starting point for learning about Feelcoin, finding official software and connecting with the network and community.

## About Feelcoin

Feelcoin is an independent Proof-of-Work blockchain project using the **RandomX** mining algorithm. The project aims to make participation accessible through CPU-oriented mining, open-source software, documented development and community involvement.

The official site connects the different parts of the ecosystem. Visitors can discover how the network works, find the official mining pool and explorer, and navigate to wallet software for different devices.

## What the website provides

### 🪙 Project introduction

An overview of Feelcoin, its identity and its guiding message: **In Feels We Trust**. The website provides a single official location from which users can reach the project's open-source resources.

### ⛏️ Mining and participation

Pointers to the official Feelcoin mining pool, miner software and mining setup information. The network uses RandomX Proof-of-Work; miners contribute computational work to help secure the chain.

| Connection type | Endpoint |
| --- | --- |
| Standard mining | `pool.feelcoin.org:4242` |
| TLS mining | `pool.feelcoin.org:4244` |

The pool website is available at https://pool.feelcoin.org. Review its current settings and guidance before connecting.

### 🔎 Block explorer

The public explorer at https://explorer.feelcoin.org gives miners and community members access to public chain information, including block lookups, transaction hashes and network statistics.

### 📱 Wallet ecosystem

Feelcoin provides several wallet interfaces for different needs:

- **Android Beta:** https://github.com/feelcoin-org/feelcoin-android
- **Desktop wallet (Windows and Linux):** https://github.com/feelcoin-org/feelcoin-desktop
- **Web wallet:** https://wallet.feelcoin.org
- **Paper wallet generator:** https://paper.feelcoin.org

Wallet users should protect their recovery seeds and private keys and carefully review beta-software notices.

### 🤝 Open development and community

The project's source code and individual component repositories are published through https://github.com/feelcoin-org. Community members can inspect code, report reproducible issues and follow development milestones.

## Repository organization

This repository hosts the public website's `index.html`, `assets/` and related website resources, with additional operational and documentation directories. Changes to this repository do not automatically demonstrate that the same changes are deployed on the live server.

## Project transparency

Feelcoin documents its development, infrastructure and protocol funding through its open-source ecosystem. Donations to support development are voluntary and are **separate from the consensus-enforced development treasury**. No donation provides governance privileges, ownership or guaranteed financial returns.

## Website security and contributions

- Use only official Feelcoin domains and verify downloads against published checksums when provided.
- Never share wallet recovery seeds, private keys or passwords with website operators or support channels.
- Report website errors or documentation issues through the relevant GitHub repository.
- Avoid publishing infrastructure credentials or wallet-sensitive information in contributions.
