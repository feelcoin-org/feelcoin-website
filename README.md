# Feelcoin Website

Official website for Feelcoin (FEEL).

Feelcoin is an independent RandomX Proof-of-Work cryptocurrency with open-source mining, explorer, wallets, and transparent protocol funding.

## Official ecosystem

- Website: https://feelcoin.org
- Mining Pool: https://pool.feelcoin.org
- Explorer: https://explorer.feelcoin.org
- Web Wallet: https://wallet.feelcoin.org
- Paper Wallet: https://paper.feelcoin.org
- GitHub: https://github.com/feelcoin-org

## Mining

- TLS: `pool.feelcoin.org:4244`
